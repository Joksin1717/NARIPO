# Kontribusi ke NARIPO

Terima kasih telah tertarik untuk berkontribusi pada NARIPO! Kami sangat menghargai semua bentuk kontribusi, mulai dari laporan bug hingga fitur baru.

## Cara Berkontribusi

### 1. Fork Repository
Klik tombol "Fork" di halaman repository untuk membuat salinan repository Anda sendiri.

### 2. Clone Repository Anda
```bash
git clone https://github.com/YOUR_USERNAME/NARIPO.git
cd NARIPO
```

### 3. Buat Branch Fitur
```bash
git checkout -b feature/AmazingFeature
```

### 4. Lakukan Perubahan
Edit file yang diperlukan dan buat perubahan Anda.

### 5. Commit Perubahan
```bash
git add .
git commit -m 'Add some AmazingFeature'
```

### 6. Push ke Branch
```bash
git push origin feature/AmazingFeature
```

### 7. Buka Pull Request
Buka pull request dari branch Anda ke branch `develop` di repository utama.

## Guidelines

### Code Style
- Gunakan TypeScript untuk semua file baru
- Ikuti ESLint configuration yang sudah ada
- Gunakan meaningful variable names
- Tambahkan comments untuk logika yang kompleks

### Commit Messages
- Gunakan format yang deskriptif: `Add feature X` atau `Fix bug in Y`
- Hindari commit message yang terlalu singkat
- Gunakan lowercase

### Pull Requests
- Tulis deskripsi yang jelas tentang perubahan Anda
- Referensikan issue jika ada: `Closes #123`
- Pastikan code Anda sudah ditest
- Update documentation jika diperlukan

## Melaporkan Bug

Jika Anda menemukan bug, mohon buatkan issue dengan informasi:
1. Deskripsi bug
2. Steps untuk reproduce
3. Expected behavior
4. Actual behavior
5. Screenshots jika ada
6. Browser dan OS yang digunakan

## Saran Fitur

Untuk saran fitur baru:
1. Jelaskan fitur yang ingin ditambahkan
2. Jelaskan use case
3. Jelaskan benefit dari fitur tersebut
4. Terbuka untuk diskusi dan masukan dari tim

## Pertanyaan?

Jangan ragu untuk menghubungi kami atau membuka discussion di GitHub!
