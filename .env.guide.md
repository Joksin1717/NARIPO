# Environment Variables Guide

## Setup

1. Copy file `.env.example` ke `.env.local`:
```bash
cp .env.example .env.local
```

2. Edit file `.env.local` dengan nilai yang sesuai dengan setup Anda

## Variables

### API Configuration
```env
# URL API backend
NEXT_PUBLIC_API_URL=http://localhost:3000/api
```

### Application
```env
# Nama aplikasi
NEXT_PUBLIC_APP_NAME=NARIPO

# URL aplikasi
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### Payment (Optional)
```env
# Public key dari Stripe
NEXT_PUBLIC_STRIPE_KEY=your_stripe_public_key

# Secret key dari Stripe (JANGAN expose di frontend!)
STRIPE_SECRET_KEY=your_stripe_secret_key
```

### Database (Coming Soon)
```env
# Database connection string
DATABASE_URL=your_database_url
```

### Authentication (Coming Soon)
```env
# JWT Secret
JWT_SECRET=your_jwt_secret_key

# Session timeout (dalam menit)
SESSION_TIMEOUT=60
```

## Development vs Production

### Development
```env
NEXT_PUBLIC_API_URL=http://localhost:3001
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### Production
```env
NEXT_PUBLIC_API_URL=https://api.naripo.com
NEXT_PUBLIC_APP_URL=https://naripo.com
```

## Important Notes

⚠️ **DO NOT COMMIT `.env.local` to Git!**

- File `.env.local` berisi sensitive data
- `.env.local` sudah ada di `.gitignore`
- Jangan share `.env.local` file Anda
- Setiap developer harus membuat `.env.local` mereka sendiri

## How to Get API Keys

### Stripe
1. Buat account di [stripe.com](https://stripe.com)
2. Go to Dashboard → API keys
3. Copy Publishable key ke `NEXT_PUBLIC_STRIPE_KEY`
4. Copy Secret key ke `STRIPE_SECRET_KEY`

### Backend API
- Set `NEXT_PUBLIC_API_URL` ke URL backend Anda
- Default: `http://localhost:3001` untuk development

## Verification

Untuk memverifikasi environment variables sudah benar, jalankan:
```bash
npm run dev
```

Check console untuk memastikan tidak ada error terkait missing variables.
